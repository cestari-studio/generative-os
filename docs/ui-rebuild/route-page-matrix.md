## 2. Critérios de Transição de Estado da Matriz

Cada tela deve percorrer os seguintes estágios:

1. **INVENTARIADO:** Mapeamento completo de rota, componentes, dados e testes existentes (Concluído).
2. **CONSULTADO_MCP:** Componentes, variantes, tokens e acessibilidade validados via Carbon MCP.
3. **IMPLEMENTADO:** Código reconstruído seguindo templates oficiais e consumindo dados reais.
4. **VALIDADO:** Aprovado em build SSR, testes automatizados, `code_audit`, acessibilidade WCAG 2.2 AA e baseline visual.
5. **BLOQUEADO:** Se faltarem dados reais no backend ou credenciais necessárias, a tela é marcada como bloqueada e exibe um estado vazio explícito, sem dados fictícios.
